# V8 direct-push package

Extract into the root of the existing working repo and replace files.

Then:

git add .
git commit -m "Add enterprise subscription routing and RG selection"
git pull --rebase origin main
git push origin main

## Routing
Internal/Intranet/DMZ:
- automatic subscription selection
- deterministic if the following App Service settings exist:
  AZURE_SUBSCRIPTION_INTERNAL
  AZURE_SUBSCRIPTION_INTRANET
  AZURE_SUBSCRIPTION_DMZ
- AZURE_SUBSCRIPTION_ID remains a backward-compatible fallback.

Business Managed:
- requires a real authenticated Backstage user
- returns only explicitly entitled subscriptions
- entitlement mapping setting example:
  AZURE_BUSINESS_SUBSCRIPTION_ENTITLEMENTS={"user:default/alice":["SUB-GUID-1"],"group:default/finance":["SUB-GUID-2"]}

The code deliberately does NOT expose all Managed-Identity-accessible subscriptions to a guest user.

## Resource groups
The VM form offers:
- Use existing: dropdown populated from selected/resolved subscription
- Create new: RG generated by naming standard

## Networking
VNet and subnet discovery is scoped to the resolved/selected subscription.
