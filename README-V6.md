https://backstage-pranab-mvp-e9gcgmasd5abgth5.centralindia-01.azurewebsites.net

- Working Backstage new frontend-system integration
- Self-Service sidebar entry
- `/self-service` page

- Marketplace-style Azure service selection

- Storage Account form

## No manual code edits are required

Extract all ZIP contents into your repository root, for example:

```text
C:\backstage-full
```

Choose **Replace files in destination**.

Then run only:

```powershell
cd C:\backstage-full

git add .
git commit -m "Deploy complete modular Self-Service V6"
git pull --rebase origin main
git push origin main
```

## Azure settings expected by the code

The existing App Service should already have:

```text
AZURE_SUBSCRIPTION_ID=<subscription-guid>
```

Optional:

```text
AZURE_ALLOWED_LOCATIONS=centralindia,southindia,westindia
```

System Assigned Managed Identity must be enabled and have sufficient RBAC on the
target Azure scope.

## Existing API URLs are preserved

```text
GET  /api/azure-self-service/config
POST /api/azure-self-service/deploy/vm
POST /api/azure-self-service/deploy/storage
POST /api/azure-self-service/deploy/app-service
```

## Important safety behavior

GitHub Actions executes:

1. Generate Self-Service source
2. Install dependencies
3. Type check
4. Build
5. Package
6. Deploy

Therefore a TypeScript/build error stops before replacing the running Azure App Service.
